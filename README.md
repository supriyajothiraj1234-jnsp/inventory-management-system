# Inventory Management System

## Overview

Inventory Management System is a simple web-based application developed using HTML, CSS, and JavaScript.

It helps users manage and monitor product inventory in an easy way.

## Features

* Simple and user-friendly interface
* Dashboard for inventory overview
* Add new products
* View product details
* Search products
* Delete products
* Display product quantity
* Show product price
* Manage supplier details
* Identify low-stock products
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Product Details

The system stores:

* Product ID
* Product Name
* Category
* Quantity
* Price
* Supplier Name
* Stock Status

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the dashboard to manage inventory.

## Purpose

This project is designed as a simple academic mini project to demonstrate basic web development and inventory management concepts.
